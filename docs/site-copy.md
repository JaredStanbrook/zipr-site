# Zipr — site copy

Every word a visitor reads, in reading order, pulled straight from the
rendered pages.

## How to use this

- **Edit the text, not the ids.** Each block is labelled `[ID]`. Rewrite what
  is underneath it and leave the label where it is.
- **Delete a block** to have it removed from the page, and say so in a note —
  some are load-bearing (a button with no label is still a button).
- **Add a block** by writing `[NEW after HOME-12]` and the text you want.
- Hand the whole file back and it gets applied to the source.

Generated by `scripts/copy-export.mjs`. Re-run it any time; the ids are
positional, so they shift if blocks are added — always work from a fresh pull.

QUESTIONS

**[PRICE-63]** _subheading_

Before you ask

**[PRICE-64]** _question_

Why is the app free if the team version isn't?

**[PRICE-65]** _text_

Because the app is complete on its own: it stores and runs everything on your machine, so it would keep working whatever we did. Sharing needs a server, and that is the part you pay for.

**[PRICE-66]** _question_

Hosted or self-hosted — which should we pick?

**[PRICE-67]** _text_

It is the same software, so choose on operations. Hosted: we run, patch and back it up, and you pay per person. Self-hosted: your data never leaves your infrastructure, it can run with no internet, and you pay per deployment. Teams with a platform group and a data-residency policy usually self-host; everyone else is better served hosted.
