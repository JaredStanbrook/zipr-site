# Translations

The header has a language button with eight languages besides English (see
`worker/content/languages.ts`). English is the source and the only thing the
server renders; the visitor's browser translates it.

## How it works

1. The language chosen is kept in local storage under `zipr-lang`. Nothing is
   sent anywhere and there is no cookie.
2. `Layout.tsx` preloads `/i18n/<code>.json?v=<assetVersion>` from an inline
   script, and `components/ui/LanguageSwitcher.ts` translates the page when it
   arrives (and again after each HTMX navigation).
3. `components/lib/translate.ts` splits the page into **sentences**: whole
   runs of inline text. Inline elements inside a sentence become placeholders
   (`<1>link text</1>`, `<2/>` for code, icons and values), so a translation can
   reorder them. Each sentence is looked up by an FNV-1a hash of its English
   text.
4. A sentence missing from the catalogue, or whose translation does not have
   the same placeholders, stays English. Editing English copy therefore never
   breaks a page; it just shows that sentence in English until the catalogue is
   updated.

Pages that stay English whatever was chosen: `/privacy`, `/licence`, `/login`,
`/register`, `/profile`, `/admin`, `/web` (`isTranslatablePath`). Mark text that
must never be translated, such as dynamic values, with `translate="no"`.

Search engines index the English pages, because translation is client-side.

## Updating translations

```sh
npm run i18n:extract   # rewrite i18n/source.json from the rendered pages
npm run i18n:status    # per language: how many sentences are still missing
npm run i18n:import -- --list [CODE]   # numbered sentences, or the missing ones
npm run i18n:import -- CODE FILE       # FILE has lines "N|translation"
```

`tests/i18n.test.ts` fails if `source.json` is out of date, if a catalogue has a
mismatched placeholder, or if a language covers under 95% of the live sentences.

## Adding a language

Add it to `LANGUAGES`, translate every line of `i18n/source.json`, and import
it. Right-to-left languages would also need layout work.

## Quality

The current translations were written with an LLM and have not been reviewed by
native speakers. The menu says so and points to the English as the original.
Review by a native speaker is advisable before relying on any of them.
